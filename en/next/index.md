# Laratype v1 (next)

Laratype v1 is a redesign of the framework. Each endpoint is declared once, as a contract, and that one object drives validation, handler types, the typed frontend client and OpenAPI. Classes get their dependencies through constructor injection, without required decorators.

v1 is not on npm yet. To build an application today, use [v0.5.4](/getting-started/introduction/quick-start).

## Status

Pages are added here as features are merged. Until then, follow the work in the tracking issue [Laratypes/Laratype#83](https://github.com/Laratypes/Laratype/issues/83).
