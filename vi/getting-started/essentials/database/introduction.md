# Giới thiệu

Gói `@laratype/database` là ORM (Object-Relational Mapping) của Laratype. Ứng dụng đọc và ghi cơ sở dữ liệu thông qua gói này.

## Cài đặt

::: code-group

```sh [npm]
$ npm install @laratype/database
```

```sh [pnpm]
$ pnpm add @laratype/database
```

```sh [bun]
$ bun add @laratype/database
```

:::

## Cấu hình

Cấu hình database nằm trong file `config/config.ts`.
