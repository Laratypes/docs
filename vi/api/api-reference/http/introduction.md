# Giới thiệu

`@laratype/http` là package để xây dựng ứng dụng web và API bằng TypeScript. Package này gồm:

- Routing: khai báo route cho các phương thức HTTP như GET, POST, PUT, DELETE.
- Middleware: viết và gắn middleware để xử lý request trước khi tới controller.
- Request và Response: các lớp và phương thức để đọc request và trả response.
